# 分房表 Draft-01

依 Draft-01 UI 製作的手機版分房表，包含一般檢視、點名模式與編輯模式。

## 功能

- 查看房間、旅客中英文姓名及完整備註。
- 新增房間後置頂，編輯房號、移動房客與加入待分房旅客。
- 儲存或取消分房修改。
- 個別與整房點名，篩選全部、已到與未到，支援重新點名。
- 點名模式的標題與進度區保持在畫面上方。

## 執行方式

此專案為純靜態網站，不需要安裝套件或建置。可使用任意靜態網站伺服器開啟，例如：

```sh
python3 -m http.server 8000
```

然後瀏覽 `http://localhost:8000`。

## GitHub Pages

在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**，來源設定為 **main / (root)**。

## 資料

頁面使用示範旅客與分房資料；修改保留在使用者目前瀏覽器的 localStorage。不同瀏覽器、裝置與網址的資料各自獨立。本專案沒有後端服務，未連接公司內部系統。
